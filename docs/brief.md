# Oto Fund ブリーフ

レビューや判断で迷ったときの基準。意見が対立したら、この文書の「目的」を優先する。

## サービス概要

Oto Fund（オトファンド）は、音楽に特化した購入型クラウドファンディング。アーティストがアルバム・ライブ・MV などのプロジェクトを立ち上げ、ファンがリターンを選んで支援する。

主な機能：
- プロジェクトの支援（All-or-Nothing / All-in、0円プラン、参加人数目標、上乗せ支援）
- 月額メンバーシップ（月額300円から。メンバーは新しいプロジェクトを公開前から支援できる）
- ONE NOTE FES（Oto Fundから生まれる、ファンと共に創る音楽フェス。現在企画中）
- 実行者向けの作成画面（AI校正、プレビュー、下書き保存）と管理画面

## ターゲット

**若手・インディーズのアーティストと、その熱心なファン。**

- アーティスト：インディーズバンド、歌い手・YouTuber・TikToker、地下アイドル、大学生・高校生バンドなど。はじめてクラウドファンディングに挑戦する人が多い
- ファン：10〜30代。推しを近くで応援したい人。1回の支援の予算は数千円が中心で、クラウドファンディングに慣れていない人も多い

メジャーアーティストも掲載できるが、言葉づかい・事例・デザインの判断は、若手・インディーズとそのファンに合わせる。

## 目的

**いちばんの目的は、プロジェクトへの支援を増やすこと。**

訪れたファンが、プロジェクトを見つけ、想いに共感し、迷わず支援（0円での参加やシェアも含む）まで進めることを最優先にする。

判断の優先順位：
1. 支援までの流れがわかりやすく、迷わない・不安にならない（信頼感、料金・決済方法・届く時期が明確）
2. アーティストの音楽と想いが伝わる（試聴、写真、ストーリー）
3. メンバーシップ、ONE NOTE FES、アーティストの掲載獲得は、支援を増やすことを妨げない範囲で伝える

## ブランドのトーン

**ポップで親しみやすい。**

- 見た目：白地に黒の文字、紫（brand）を主役に、黄・ピンク・青・緑の差し色。写真を大きく使い、丸・三角・四角の図形ステッカーで遊びを入れる。スクロールに合わせた動きで楽しさを出す
- 言葉：やさしく、短く、話しかけるように。専門用語（All-or-Nothing など）には一言の説明を添える
- 「好き」を応援する気持ちに寄り添う。押しつけない

## やらないこと

- **誇大表現・煽り**：根拠のない「No.1」「日本初」「最高」、確約できない「絶対」「必ず」、不安をあおる「残りわずか」の多用。購入型なので「投資」「配当」「寄付」とも書かない
- **他社名を出した比較**：TikTok や他の会員サイト・クラウドファンディングを名指しで比べない。Oto Fund 自身の良さで伝える

## 守ること（事実・制約）

- 金額はすべて税込・送料込みで表示する
- 手数料は 16%＋税（決済手数料込み、仮）。大手の購入型より1%低い水準。ただしサイトでは他社と比べない。「◯%がアーティストに」という還元率の打ち出しもしない。手数料の一部を ONE NOTE FES の開催費用にあてる。**あてる割合は未定なので数字を出さない**
- ONE NOTE FES の日程・会場・出演者は未定。決まっていないことは書かない
- 法務ページ（利用規約・プライバシーポリシー・特定商取引法に基づく表記）は、公開前に専門家の確認を受ける前提のたたき台
- 現在はデモ。ログインや支援の記録はブラウザ内に保存しており、決済（Stripe）とデータベース（Supabase）は未接続
