Features

音楽のための機能

  • 試聴プレイヤー

    ページの一番上で、あなたの音楽をすぐ聴いてもらえます。

  • 0円プラン・参加人数目標

    お金をかけずに「応援したい」「ライブに行く」を集められます。

  • 音楽のためのリターン

    先行配信は自動でお届け、ライブチケットはQRで自動発行。

  • 月額メンバーシップ

    プロジェクトの合間も、毎月の応援を。メンバーは次のプロジェクトの最初の支援者になってくれます。

  • AI校正

    誤字脱字や、審査で差し戻されやすい表現をその場でチェック。修正案はワンクリックで反映できます。

  • プレビューと下書き保存

    支援者にどう見えるかをPCとスマホで確認。入力は自動で下書き保存されます。

  • ONE NOTE FES

    Oto Fundで挑戦したアーティストが集まる音楽フェスを企画中。手数料の一部が開催費用になります。

  • 高校生・大学生も

    18歳未満の方も、保護者の同意があれば挑戦できます。

Rewards

リターン設計のコツ

1回の支援は数千円が中心になりやすいので、リターンは3〜5種類にしぼり、価格帯をばらけさせましょう。

  • 0円応援・参加表明。支援者の母数を増やし、シェアのきっかけに。
  • ¥1,500〜¥3,000主力のリターン。音源の先行配信やCDなど、選ばれやすい価格帯の目安です。
  • ¥5,000〜¥10,000ライブ招待、サイン、クレジット掲載など「ここでしか手に入らない」もの。
  • ¥30,000〜レコーディング見学など、少数限定の体験。
